# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-08-10

### Added
- Initial scaffold of the VeloMetric iOS MVP.
- Core Data Models (`Bike`, `Component`, `Ride`).
- `GarageViewModel` with mock data simulation.
- `DashboardView` with glassmorphic UI and circular progress rings.
- GitHub Actions for Swift build and testing.
- Comprehensive repository documentation and Open Source templates.
