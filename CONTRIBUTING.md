# Contributing to VeloMetric

First off, thank you for considering contributing to VeloMetric! 

## 🛠️ Development Process

1. **Fork** the repo and create your branch from `main`.
2. **If you've added code** that should be tested, add tests.
3. **Ensure the test suite passes** (`swift test`).
4. **Format your code** using standard SwiftLint rules.

## 📝 Pull Request Guidelines

- Fill out the provided Pull Request template.
- Keep PRs small and focused on a single feature or bug fix.
- Link the PR to a specific Issue using `Fixes #ISSUE_ID`.

## 🎨 Styleguides

- **Swift**: Follow the [Swift API Design Guidelines](https://swift.org/documentation/api-design-guidelines/).
- **UI**: Adhere to Apple's Human Interface Guidelines (HIG).
